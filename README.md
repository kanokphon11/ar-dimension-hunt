# AR Dimension Hunt

เกมล่าขุมทรัพย์ AR สำหรับนักเรียน ป.4–ป.6

## โครงระบบ
- Frontend: GitHub Pages
- Backend/API: Google Apps Script
- Database: Google Sheets
- GPS + Camera AR: ใช้งานผ่าน HTTPS

## Deploy
1. อัปโหลดไฟล์ `game.zip` ไว้ที่ root ของ repository นี้
2. ไปที่ **Settings → Pages**
3. ที่ **Build and deployment → Source** เลือก **GitHub Actions**
4. กลับมาที่แท็บ **Actions** แล้วรอ workflow **Deploy AR Dimension Hunt** ทำงาน
5. เว็บไซต์จะอยู่ที่:
   **https://kanokphon11.github.io/ar-dimension-hunt/**

> ไฟล์เกมภายใน ZIP ต้องมี `index.html` และ assets ของเกม
